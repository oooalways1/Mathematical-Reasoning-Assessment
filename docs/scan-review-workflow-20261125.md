# 무료 OCR 인식 후 사람이 확인하는 제출 흐름

2026-11-25. 사용자가 기존 무료 OCR과 수동 확인 방식을 선택했다. 이미지 AI나 새 API 키를 연결하지 않는다.

## 화면과 동작

1. PDF/JPG/PNG 파일을 기기 안에서 무료 OCR로 읽고, 인식한 **학생 답안**을 임시 입력한다. 이 시점에는 채점·저장하지 않는다.
2. 업로드 원본과 문항별 답안을 나란히 보여 준다. 원본 쪽 선택과 확대를 제공한다. 좁은 화면에서는 원본과 입력칸을 위아래로 배치한다.
3. 자동 입력도 모두 ‘확인 필요’로 시작한다. 빈칸은 ‘직접 입력 필요’, 충돌한 인식 결과는 별도로 표시한다. 인식기의 불확실 표시가 없어도 사람이 모든 문항 번호와 답을 확인한다.
4. 답을 수정하거나 읽지 못한 칸을 채운 뒤 문항별 ‘원본과 같아요’를 누른다. 실제로 답을 쓰지 않은 문항은 ‘원본에도 답이 없어요’를 선택하여 미응답으로 확정할 수 있다. 정답표에 맞춰 답을 바꾸도록 유도하지 않는다.
5. 모든 문항 확인 후 최종 확인란을 선택해야 제출할 수 있다. 확인 후 답을 수정하면 해당 문항과 최종 확인이 해제되고 제출도 다시 차단된다.
6. 수정·확정한 답안을 기존 채점·저장 API로 전달한다. 실제 미응답은 기존처럼 오답이다. 학생의 입력 문자열과 평가 버전 연결은 기존 형식을 유지한다.

학생이 본인 답안을 확인하거나, 교사가 학생과 함께 같은 제출 화면에서 확인할 수 있다. 별도 교사 대리 로그인이나 일괄 업로드 권한을 추가하는 변경은 아니다.

파일 재인식, 평가 변경, 입력 방법 변경 시 확인 상태를 초기화한다. 기존 답이 있는 상태에서 재인식·평가·입력 방법을 바꾸려 할 때는 답안 삭제 안내를 표시한다. 파일 자체를 교체하면 해당 파일 기준으로 새로 시작한다.

## 검증

- 앞서 OCR 정확도가 0/20이었던 삐뚤빼뚤한 합성 필기 PDF를 **실제 Diagnosis 컴포넌트**의 파일 선택창으로 다시 선택했다.
- 실제 파일 인식에서 6문항에 잘못된 임시 답이 채워지고 14문항은 비었다. 모든 20문항이 확인 대상으로 표시됐으며 최종 확인·제출은 비활성화됐다.
- 원본을 보며 실제 화면의 입력칸 20개를 수정·채우고 문항별 확인 버튼을 눌렀다. 실제 빈칸 확인 후 다시 답을 입력하면 그 문항의 확인이 해제되는 것도 검증했다.
- 문항별 확인 완료만으로는 제출되지 않는다. 최종 확인 후에만 제출 버튼이 활성화됐다.
- 최종 확인 이후 7번을 `15`에서 `1 5`로 바꾸자 확인이 19/20으로 되돌아가고 최종 확인도 해제됐으며 제출은 다시 막혔다.
- 재확인 후 제출한 실제 JSON에는 OCR 초안이 아닌 사람이 수정한 답이 담겼다. `6, 10`, `1 / 2`, `나 라`, `1 5` 등 공백 있는 답이 유지됐고 같은 소스의 채점 엔진에서 **100/100점**이었다.
- 이 브라우저 검증은 로컬 가상 학생과 가상 저장 API를 사용했다. 운영 계정·DB 제출 테스트가 아니며, 손글씨 OCR 정확도가 개선됐다는 뜻도 아니다.
- 로컬 증거: `outputs/scan-review-browser-gates-20261125.json`, `outputs/scan-review-browser-submission-20261125.json`, `outputs/scan-review-ui-20261125.jpg`, `outputs/scan-review-result-20261125.jpg`.
- 자동 검증: `scripts/verify-scan-review.mjs`, 공백 채점 323개 검사, 학교 통합·학교 관리·평가 버전 검증 통과. TypeScript 검사와 빌드 통과.

## 배포 영향

- DB 마이그레이션, Firebase 설정, Cloudflare Secret·AI 바인딩 변경 없음.
- OCR 원본은 서버에 저장하지 않는다. 기존 기록을 재채점하지 않는다.
- 이전 손글씨 자동 인식 통과 조건은 실패로 기록된 상태를 유지한다. 이번에는 사용자가 선택한 **사람의 수정·확정 이후 제출 흐름**을 검증했다.
- main push와 운영 배포는 변경 내용 및 검증 결과 보고 후 사용자 승인 절차에 따른다.
