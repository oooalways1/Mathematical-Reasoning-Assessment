# 상황별 피드백 구성

## 제공 방식

개발 단계에서 AI의 도움으로 풀이 안내와 상황별 문구를 미리 작성했습니다. 실제 이용 중에는 학생 데이터를 외부 AI 서비스로 보내거나 생성형 AI API를 호출하지 않습니다. 서버가 채점 결과, 같은 기준의 이전 진단, 실제 연습 답안 이력에 따라 준비된 안내를 선택합니다.

- 학습 내용 카드 54개: 1학년 20개, 2학년 원 문항 14개, 3학년 20개. 2학년의 1학년 연결 문항은 1학년 카드와 연결합니다.
- 진단 상황 14개와 연습 상황 16개, 총 30개의 선택 조건.
- 상황별 문구 2가지를 학습 내용 카드에 연결하고 문항 유형에 맞지 않는 상황을 제외하여 2,580개의 사전 작성 조합을 제공합니다.
- 전체 결과 요약은 8가지 상황으로 제공합니다. 위 2,580개 조합 수에는 포함하지 않습니다.
- 조합 수는 독립적인 오개념 2,580종을 의미하지 않습니다. 같은 상황 안내에 학습 내용별 초점과 다음 활동을 결합한 수입니다.

전체 조합은 생성한 `outputs/feedback-catalog.json`에서, 교사용 미리보기는 관리페이지의 **피드백 자료**에서 확인할 수 있습니다. GitHub에는 카드·상황 문구와 생성 스크립트를 저장하며 전체 조합 파일은 필요한 기기에서 다시 생성할 수 있습니다.

## 진단 상황 14개

첫 정답, 같은 기준에서 연속 정답, 이전 오답 후 정답, 등록된 다른 허용 답, 첫 미입력, 반복 미입력, 파일 답안 미입력 확인, 이전 정답 후 오답, 동일 오답 반복, 다른 답으로 재도전, 선택형 보기 확인, 단답형 풀이 확인, 수 부분이 같은 표기 확인, 정답과 1 차이.

이전 진단 비교는 같은 학생·학년·정답표 버전인 기록에만 적용합니다. 이전 채점 결과와 정답 스냅샷은 변경하지 않습니다. 원래 검사지의 지문과 풀이가 없는 상황에서 특정 오개념을 확정하지 않습니다. 숫자와 단위의 표기 확인은 채점 변경이 아니라 교사 확인 안내입니다.

## 연습 상황 16개

아직 시작하지 않음, 첫 시도 정답, 오답 후 정답, 두 번 연속 정답, 정답 경험 후 오답, 첫 오답, 동일 오답 반복, 다른 답으로 재도전, 네 번 연속 오답, 단위 확인, 답 형식 확인, 부등호 방향, 계산 기호, 두 자리 수의 자리 순서, 정답과 1 차이, 세 번 연속 정답 후 설명 확장.

연습은 원 검사지와 별도로 만든 문제가 있어 식·정답·단위를 기준으로 구체적인 확인 안내를 제공합니다. 같은 연습을 반복해서 맞힌 것만으로 개념 습득이나 진단 성적 향상을 판단하지 않습니다. 안내는 기록된 답의 특징을 짚고 풀이 확인을 권합니다.

## 학습 내용 카드

각 카드에는 초점, 풀이 3단계, 확인 방법, 더 쉬운 활동, 다음 도전, 교사 관찰 질문이 있습니다. 학생이 힌트를 펼치거나 오답 후 다시 연습할 때 다음 단계의 힌트를 제공합니다. 교사는 모두 미리 볼 수 있습니다.

## 저장과 기존 기록

새 진단은 선택한 피드백과 학습 안내를 기존 답안 결과 JSON에 함께 저장합니다. 새 연습은 매 시도마다 선택한 피드백을 `learning_attempts.coaching`에 저장합니다. 교사 의견은 별도로 유지합니다.

기존 상세 피드백이 있는 기록은 저장된 정오 판단에 준비된 학습 안내를 연결해 표시합니다. 상세 정보가 없는 이전 진단에는 오답이나 특정 오개념을 새로 추정하지 않습니다. 기존 연습의 안내는 기록을 바탕으로 계산해 표시하고, 새 연습부터 선택 당시 문구를 저장합니다.

마이그레이션 `0006_adaptive_coaching.sql`은 연습 시도에 안내 JSON 열을 추가합니다. 기존 진단과 연습 행은 보존합니다.

## 원본 재현

학습 카드나 상황 문구를 수정했다면 `node scripts/export-feedback-catalog.mjs`로 전체 조합 자료를 다시 생성하세요. 이 과정은 사전 작성 자료의 조합을 내보내며 학생 데이터나 API 키를 사용하지 않습니다.
