## 실제 운영 확인

가상 계정과 가상 문항만 새로 만들어 다음을 확인했다.

1. 기존 공용 관리자 로그인 유지.
2. 운영 Firebase 서비스 계정을 통한 새 학교 관리자 발급, 비밀번호 로그인.
3. 다른 학교 학생 목록 요청 403 차단.
4. 학생의 아이디 방식 가입·로그인 및 학교 연결.
5. `나, 라` 정답에 `나 라`를 제출하면 정답 인정. 다른 연산 문항의 오답 판정도 확인.
6. 실제 운영 AI 생성 → 교사 검토 상태 → 검토 전 학생 비공개 → 승인 후 학생 표시.
7. 학교 관리자 비활성화 후 이미 발급한 세션도 즉시 401.

가상 Firebase 계정 2개와 정확히 해당하는 시험 학생·평가·진단·관리자 DB 행은 정리했다. 기존 계정과 답안은 변경하지 않았다. 시험 행의 생성·권한 변경 감사 기록은 남는다. 기존 공용 관리자 로그인 종료 설정은 끄지 않았다.

## 사용 방법

- 기존 관리자는 관리페이지에서 아이디를 비우고 기존 비밀번호로 로그인한다.
- `관리자·AI 사용량`에서 원하는 새 관리자 아이디, 역할, 담당 학교, 임시 비밀번호를 설정한다.
- 새 총괄 관리자 로그인을 직접 확인한 뒤 공용 로그인을 종료할 수 있다. 이번 배포에서는 공용 로그인을 종료하지 않았다.
- 학교를 선택하고 `정답 설정`에서 해당 학교의 평가를 생성·복사·수정한다.
- AI 피드백은 교사가 내용을 확인·수정하고 승인해야 학생에게 표시된다.

## 한계와 운영 주의점

- AI 생성은 현재 앱 전체 하루 최대 45회, 학생당 최대 3회다. 초과/실패 시 채점·저장을 유지하며 기본 안내를 제공한다. 300명 전원에게 같은 날 AI 생성을 보장하는 설정은 아니다.
- 실제 아동 손글씨와 촬영 품질별 OCR 정확도는 대표 자료로 추가 확인해야 한다. 불확실한 답을 자동 확정하지 않는다.
- Google 팝업 로그인과 초대 메일 자동 발송은 제공하지 않는다.
- 자동 검산 가능한 3단계 연습은 지원되는 연산 범위에 한정한다. 다른 주제는 교사 검증 자료가 필요하다.
- 기존 [배포 전 검증 기록](school-integration-validation.md)과 [격리 시험 결과](school-integration-results.json)는 승인 전 시점의 기록이다. 이후 운영 반영 여부는 이 문서가 최신이다.
